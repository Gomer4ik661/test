# 📟 Текстовый браузер в Telegram

Личный бот: ищет в интернете, показывает сайты чистым текстом и присылает файлы.

- `найди нокиа 6300` (или просто `нокиа 6300`): поиск через DuckDuckGo, результаты открываются кнопками-номерами;
- `example.com` или любая ссылка: страница текстом, без картинок, рекламы и скриптов. Длинный текст листается кнопками, есть список ссылок со страницы;
- `скачай https://…/game.jar`: бот скачает файл и пришлёт его в чат. Ссылки на файлы (jar, pdf, zip, картинки…) он и так присылает файлом, до 50 МБ (это предел Telegram).

Бот отвечает только тем, чей ID указан в `ALLOWED_USERS`, чтобы чужие люди не пользовались им за ваш счёт.

## Запуск

1. В Telegram напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, задайте имя и получите **токен**.
2. Установите Python 3.10 или новее и выполните в папке `search_bot`:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и вставьте туда токен.
   **Никому не показывайте токен и не коммитьте его**: файл `.env` уже в `.gitignore`.
4. Запустите `python bot.py` и напишите боту что угодно. Он ответит вашим ID:
   впишите его в `.env` как `ALLOWED_USERS=123456789` и перезапустите бота.

### В Termux

```bash
pkg install python git
git clone https://github.com/gomer4ik661/test
cd test/search_bot
pip install -r requirements.txt
cp .env.example .env
nano .env        # вставить токен и ID, сохранить: Ctrl+O, Enter, Ctrl+X
python bot.py
```

Бот работает, пока открыт Termux. Чтобы Android его не усыплял, потяните шторку
уведомлений и в уведомлении Termux нажмите **Acquire wakelock**.

## Про экономию трафика

Трафик экономится, только если бот запущен **не на этом телефоне**, а на сервере
или домашнем компьютере: тогда тяжёлую страницу скачивает сервер, а телефону
приходит лишь текст в несколько килобайт. Если запустить бота в Termux на том же
телефоне, страницы будет качать сам телефон.

## Ограничения

- Сайты, которые без JavaScript показывают пустую страницу, так прочитать не получится.
- Иногда DuckDuckGo временно не отвечает на частые запросы; тогда подождите минуту.
- Ссылки и страницы бот помнит в памяти: после перезапуска старые кнопки перестают работать.
