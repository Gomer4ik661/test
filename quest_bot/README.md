# 🕯 Письмо от бабушки: хоррор-квест для Telegram

Текстовый квест с выбором через кнопки: 23 сцены, 5 концовок, предметы и подсказки.
Прогресс и открытые концовки каждого игрока сохраняются.

## Запуск

1. В Telegram напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, задайте имя и получите **токен**.
2. Установите Python 3.10 или новее и выполните в папке `quest_bot`:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и вставьте туда свой токен.
   **Никому не показывайте токен и не коммитьте его**: файл `.env` уже в `.gitignore`.
4. Запустите бота:
   ```bash
   python bot.py
   ```
   Бот работает, пока открыто это окно.

Команды бота: `/start` (начать или продолжить), `/restart` (заново), `/endings` (открытые концовки).

## Как менять сюжет

Весь сюжет лежит в `story.yaml`, формат описан в начале файла. После правок проверьте его:
```bash
python validate.py
```
Скрипт найдёт битые переходы, тупики, недостижимые сцены и концовки.

## Файлы

| Файл | Что внутри |
|---|---|
| `story.yaml` | сюжет |
| `bot.py` | Telegram-часть (aiogram 3) |
| `engine.py` | логика квеста: переходы, флаги |
| `storage.py` | сохранения в SQLite (`quest.db`) |
| `validate.py` | проверка сюжета |
